Query Rewriting and Expansion

Real user queries are short, ambiguous, and often conversational. A question such as "what about the memory thing again" carries almost no retrievable signal. Query rewriting transforms the raw input into a form that retrieves better, and it is one of the cheapest available improvements to a RAG system because it changes only the query rather than the index.

Rule-based cleanup is the least expensive strategy. Normalizing whitespace and casing, stripping filler, and expanding known domain acronyms costs microseconds and requires no model call. Expanding an acronym is particularly effective because the expanded form gives the dense retriever meaningful tokens to work with while the original abbreviation continues to serve the lexical retriever.

LLM-based rewriting asks a small fast model to restate the question more precisely before retrieval. This resolves pronouns, incorporates conversation history, and converts vague phrasing into specific terminology. The cost is an additional model call on the critical path of every request.

Hypothetical Document Embeddings, known as HyDE, inverts the usual approach. Rather than embedding the question, the system asks a model to write a plausible answer and embeds that instead. The reasoning is that an answer resembles the passages being searched for far more closely than a question does, since questions and answers occupy different regions of embedding space. HyDE often improves recall substantially, and it fails when the model's hypothetical answer is confidently wrong in a way that pulls retrieval toward the wrong region.

Multi-query expansion generates several paraphrases of the question, retrieves for each, and fuses the results with reciprocal rank fusion. This provides robustness against a single unlucky phrasing missing relevant passages, at the cost of multiplying retrieval work.

Every one of these techniques should be validated against a golden set before adoption. Query rewriting can degrade retrieval as easily as improve it, particularly when a rewrite discards a rare exact term that the lexical retriever depended on.
