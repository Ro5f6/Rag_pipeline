Prompt Construction, Grounding, and Citations

The final assembly step of a RAG pipeline turns retrieved passages into a prompt. This stage looks mechanical and quietly determines whether answers are trustworthy.

Grounding means instructing the model to answer only from the supplied context rather than from parametric knowledge acquired during training. Without an explicit instruction, a model will happily blend what it remembers with what it was given, producing an answer that sounds authoritative and cannot be traced to any source. The instruction must also grant permission to fail: a model told it must answer will invent something when the context is insufficient, whereas a model told to state plainly that the context does not contain the answer will usually do so.

Structure is what makes citation possible. Each passage is labeled with a bracketed number and its source filename before being inserted into the prompt, and the model is instructed to cite those numbers inline. Because the model can only reference numbers it was handed, it cannot fabricate a source. A post-processing step then maps each emitted marker back to the chunk it came from, producing an answer where every claim is auditable.

Ordering matters more than it should. Models attend unevenly across long contexts, favoring the beginning and the end while attention sags in the middle. This is why reranking pays off twice: it removes irrelevant passages, and it places the strongest passage where the model is most likely to actually use it.

Context length is a budget, not a target. Filling a large context window with twenty marginally relevant passages typically produces worse answers than five highly relevant ones, while costing far more per request. More context is not more information; it is more opportunity for distraction.

Retrieved documents must be treated as untrusted input. A passage in the knowledge base can contain text that reads as an instruction, and a model that cannot distinguish data from directive may follow it. Delimiting the context clearly, and stating that its contents are reference material rather than commands, is the minimum defense.
